What is SQL Injection?

SQL Injection (SQLi) is a cyberattack where a malicious actor inserts their own database commands into a website's input fields (like a search bar or login form). If the website is vulnerable, it will execute these commands, potentially revealing sensitive data, destroying information, or granting unauthorized access to the system.
