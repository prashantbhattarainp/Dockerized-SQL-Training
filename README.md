🛡️ SQL Injection Training Lab
---------------------------------------------------------------------------------------------------------------------------------------------------

A safe, Dockerized environment to practice SQL Injection attacks. This project simulates a vulnerable school website to demonstrate how attacks work and how to fix them.

🚀 Quick Start
Clone the repo:

Bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
Run with Docker:

Bash
docker compose up --build
Open in Browser:
Go to http://localhost:5000

✨ Key Features
Vulnerable Login: Practice bypassing authentication on the Student and Faculty portals.

Blind SQLi: Practice extracting data from the "Course Lookup" feature.

Educational Reports: The app analyzes your attacks and explains why they worked in real-time.

🛠 Tech Stack
Python (Flask) - Web Backend

MySQL - Database

Docker & Docker Compose - Containerization
